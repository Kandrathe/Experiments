## Structure (per psalm)

1. **Suno Style Metadata** — genres, sounds like, mood, vocals, arrangement, instrumentation, tempo, production, structure, dynamics, emotions
2. **Original Text (KJV)** — the scripture
3. **Summary** — what we think it means
4. **Verses (Original Song Lyrics)** — the lyrical verses
5. **Chorus (Original Song Lyrics)** — the hook
6. **Final Lyrics (Original Song Lyrics)** — the complete song, polished
