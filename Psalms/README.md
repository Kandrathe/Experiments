# Psalms Project — Memory Lake

A living archive of the Psalms, turned into song.

## Structure (per psalm)
1. **Original Text** — King James Version
2. **Summary** — what we think it means
3. **Verses** — lyrical verses
4. **Chorus** — the hook
5. **Final Lyrics** — the complete song
